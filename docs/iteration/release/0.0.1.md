# 0.0.1

发布日期：2026-10-02

首个可运行版本：dev build 下闹钟通知（横幅+铃声）验证通过。

## 功能迭代

### 1. 闹钟 MVP 完整实现

基于 001 spec（闹钟 MVP 含周期闹钟核心功能）完成从数据层到 UI 的全链路：

- 数据层：SQLite（expo-sqlite）持久化 + 仓库模式，闹钟 CRUD 与周期规则存储
- 业务层：调度器（scheduler）基于日期工具（date-utils）计算周期闹钟的下一次触发时间，通知调度委托 expo-notifications 批量预调度
- UI 层：闹钟列表、创建/编辑表单、设置页，原生时间选择器
- 测试：调度器与日期工具单元测试（jest），覆盖周期间隔与边界日期

### 2. 提醒页面 Eva 风格视觉刷新

按 002 spec（UI 视觉与交互优化）对提醒页面整体换肤为 Eva 风格，原生时间选择器替换为 Eva 风格自定义控件（含循环滚动修复与 24 小时制统一），提醒卡片统一类型与日期信息展示。同时替换了废弃的 `onChange` API 为 `onValueChange`/`onDismiss`，保证 Expo SDK 56 兼容。
