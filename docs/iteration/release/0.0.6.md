# 0.0.6

发布日期：2026-10-04

## 功能迭代

### 1. 界面全面皮肤化：弹窗与原生选择器接入统一皮肤

解决「部分 UI 仍是系统原生青绿配色、与 App 紫色皮肤割裂」的问题，建立两层皮肤体系并让所有弹窗类 UI 走统一皮肤：

- 新增 SKIN 语义色层（brand / surface / line / text / state / status / misc 七个语义组），COLORS 变为由 SKIN 派生的兼容层，300+ 处旧引用零改动平滑迁移；Android 侧 colors.xml 以 skin_* 镜像同步
- 新增 SkinAlert 皮肤化弹窗（与系统 Alert 同签名的命令式 API + 全局宿主，宿主未挂载时自动降级系统弹窗），替换全部原生 Alert 调用点：白卡片、紫色确认按钮、红色危险按钮
- 新增 SkinDatePicker 统一封装原生日期弹窗：走 MaterialDatePicker 并接皮肤主题（紫色按钮、白卡片、选中态），全中文界面（选择日期/中文月份/星期/取消确定，per-app locale 强制 zh-CN）；表单与周期设置三处统一改用
- 时间选择弹窗遮罩接入皮肤半透明色；铃声选择弹窗卡片增加间距、「马林巴」改名「木琴」

### 2. 表单交互完善：底部操作统一 + 离开前二次确认

- 编辑页底部操作区统一：保存按钮固定底部常驻（不再随内容滚动消失），删除弱化为底部小字红色链接，创建/编辑两页操作方式一致
- 新建/编辑页离开保护：有未保存改动时，点返回、硬件返回键、放弃修改弹窗均走皮肤化二次确认，确认后不产生脏数据；修复脏标记在 setState updater 内回调父组件导致的渲染期更新报错

### 3. 时间选择器修正：分钟滚轮跨圈循环不再联动改小时

修复分钟滚轮从 59 滚到 0（或反向）跨圈循环时被误判为进位/退位、连带修改小时的问题，跨圈只循环分钟数值。

### 4. 页面视觉一致性打磨

- 四个 Tab 的「英文眉标题 + 中文主标题」页头统一对齐为左 20 顶 12（此前各页 2~22px 不等，切换时有肉眼可见跳动；全部页空状态标题几乎贴边的隐藏问题一并修复）
- 计划页时间轴补齐最左侧竖线，网格边框完整闭合

## 工程与平台迭代

### 1. 主题常量收敛

COLORS 从散落多文件收敛到 `src/constants/theme.ts` 统一维护，palette（原始色板）与 SKIN（语义色）分层，为后续换肤与色彩调整提供单一事实来源。

## 文档与规范迭代

### 1. 页面布局规范沉淀

`.ai/rules/typescript-react-native-style.md` 新增「页面布局规范」章节：页面容器统一 paddingHorizontal 20、页头 paddingTop 12，禁止各页自定边距、禁止页头内层叠加 paddingHorizontal，空状态无容器包裹时需自行补齐水平边距；新开页面默认遵循。
