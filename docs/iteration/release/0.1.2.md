# 0.1.2

发布日期：2026-10-05

## 功能迭代

### 1. 设置页照 008 原型重做：分组卡片样式 + 关于卡片

- 设置页从旧版行样式重构为 008 原型的分组卡片形态：圆角卡片分组、行分隔线、按压态，与全 App 皮肤体系统一
- 新增「关于」卡片，版本号动态读取 `expoConfig.version`，不再硬编码（配合迭代版本号流转，APK 版本与展示版本不再漂移）
- 应用名定为「钟意」：launcher 图标名与关于卡片同步更新

### 2. 默认主题解锁「跟随系统」

- 新装/未设置过主题时默认跟随系统深浅色（`userInterfaceStyle: automatic`），深色系统用户首启即深色皮肤
- 主题三档（跟随系统/浅色/深色）在设置页可选，切换即时生效

### 3. 响铃浮层：响铃时 App 内即可「关闭 / 稍后提醒」

- 此前响铃交互完全依赖通知横幅/全屏意图，App 在前台或横幅被 ROM 限制时，用户听得到铃声却没有任何关闭入口，只能杀 App
- 新增 RingOverlayHost：每秒轮询原生响铃快照（RingService 响铃期间置位 `ringingInfo`，新增 `getRingingInfo` 同步接口），前台检测到响铃即弹出全屏浮层，展示闹钟标题并带「稍后 N 分钟」「关闭」按钮
- 关闭 = 停止本次响铃；稍后提醒 = 按闹钟贪睡分钟数原生重排一次触发后停止，与通知按钮语义一致

## 工程与平台迭代

### 1. 修复 release 包内置铃声被资源收缩裁掉（响铃回退系统默认音）

- 根因：release 开启资源收缩（shrinkResources）后，内置铃声 `res/raw/ars_*.ogg` 仅被 `getIdentifier` 动态引用、零静态引用，被收缩器全部裁掉，响铃永远回退到系统默认闹铃声（debug 包不收缩所以无法复现）
- 修复一：app 模块新增 `res/raw/keep.xml`（`tools:keep="@raw/ars_*"`）保留规则
- 修复二：`RingService.resolveSoundUri` 两级查找兜底——模块 `ars_*` 未命中时改查 RN 插件从 JS assets 派生的 `assets_sounds_ars_*` 资源名（release 包内始终存在），双保险保证内置音可用
