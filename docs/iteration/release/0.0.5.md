# 0.0.5

发布日期：2026-10-04

## 功能迭代

### 1. 每个提醒独立铃声：10 个内置提示音 + 本地音乐

解决「所有提醒一个单调系统音」的问题，每个闹钟可独立配置铃声：

- 内置 10 个免版权提示音，按「刺耳 / 温和 / 自然」三档分组：刺耳（Classic Alarm 默认音、Buzzer、Radar Ping）、温和（Radar Soft、Marimba、Piano Arpeggio、Music Box、Chime）、自然（Birds Morning、Ocean Waves）；统一单声道 OGG Vorbis、-1dB 峰值响度归一化，总体积仅 416KB
- 创建/编辑表单新增「铃声」选择项：三档分组列表、逐项试听（可播可停）、当前选中标记；未配置时默认 Classic Alarm
- 本地音乐铃声：从设备音乐库选歌回填歌名显示，优先级高于内置音；音乐文件失效后响铃自动回退不报错
- 铃声选择随响铃计划同步到原生模块（soundId / soundUri 双字段，本地音乐优先），触发时 RingService 按所选铃声播放；三级回退保底（本地音乐 URI → 内置音资源 → 系统默认闹钟铃声），任何一层失效都不中断响铃
- 平台策略不变：iOS / Expo Go 铃声选择可展示但不生效，响铃维持系统通知声（iOS 落后项已记录到 spec，未来开发 iOS 时必读）

### 2. 响铃链路三处缺陷修复（含 0.0.4 遗留关键 bug）

模拟器全链路实测中发现并修复，修复后响铃实测精确触发（偏差毫秒级）、播放 30 秒自停：

- 原生模块访问修复（0.0.4 遗留）：New Architecture 下 `NativeModules.AlarmRing` 恒为 undefined，导致 0.0.4 的原生响铃从未真正生效、一直静默走通知降级路径；改用 `requireOptionalNativeModule` 后 RingService 才真正接手响铃
- 当天一次性/周期闹钟不响：调度范围起点与零时时间戳精确比较，把「今天」误判为已过去，导致当天的一次性/周期闹钟 triggers 为空、不挂任何触发；入口做天级归一修复，补回归测试
- 新装用户闹钟延迟：Android 13+ 仅声明 SCHEDULE_EXACT_ALARM 时默认拒绝，调度降级为非精确触发（实测延迟 100 秒响）；补声明闹钟类应用专用的 USE_EXACT_ALARM 自动授予
- 附带修复：铃声计划 JSON 的显式 null 被 optString 读成字符串 "null"，响铃时误当本地音乐 URI 打开后才回退，解析层归一化修复

## 工程与平台迭代

### 1. 内置音源合成管线

ffmpeg 合成脚本（modules/alarm-ring/tools/）统一加工 10 个音源：转单声道 OGG Vorbis、响度归一化、时长控制、`ars_` 前缀命名；支持 FFMPEG_BIN 环境变量指定替代编码器（绕开 brew 沙箱限制的 ffmpeg-static 方案）；产物双份落位（原生 res/raw + JS assets），格式/时长/体积校验进测试。

### 2. JS 资产通道与依赖

- Metro assetExts 追加 ogg，铃声选择器可 require 内置音做试听
- 新增依赖 expo-audio（试听播放）与 expo-media-library（音乐库选歌）
