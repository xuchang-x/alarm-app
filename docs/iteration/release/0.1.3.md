## 功能迭代

### 1. 响铃全屏界面：App 被杀/锁屏下弹窗稳定弹出，不再依赖 App 前台

- 业界实践调研后落地方案 A（AOSP/Google 时钟同构）：响铃通知的全屏意图（FullScreenIntent）由 launcher 改为指向新增的专用原生 `AlarmRingActivity`，息屏/锁屏/App 退后台/进程被杀（`am kill` 级）时闹钟触发直接全屏弹出响铃界面，实测毫秒级显示（~107ms，纯原生零 JS 冷启动），并自动请求解锁 Keyguard（showWhenLocked + turnScreenOn + excludeFromRecents）
- 全屏意图权限受限时系统自动降级为 heads-up 横幅，仍保留关闭/稍后提醒入口；App 在前台时维持原 RingOverlay 浮层不变（双通道互补）
- 停止联动：RingService 停止响铃（关闭/贪睡/30 秒自动停）广播 ACTION_RING_STOPPED，响铃界面收到后自动退出，铃声停界面不停的问题不存在
- 界面与皮肤一致：原生 `skin_*` 资源色（模块默认值 + app 层 values/values-night 同名覆盖），并在 attachBaseContext 按 RingStore 持久化的皮肤选择（浅色/深色/跟随系统）强制 uiMode，响铃页深浅色与 App 内主题设置完全一致
- 实测（模拟器）：杀进程 + 熄屏锁屏下 16:23 闹钟精确触发，全屏界面盖锁屏弹出，关闭按钮一键停止并退出无残留

## 工程与平台迭代

### 1. 模块资源注记与 aapt2 兼容

- alarm-ring 模块新增 res（layout/drawable/values）后首次走通库模块资源链路；踩坑记录：values/*.xml 的注释必须位于 `<resources>` 根元素内部，aapt2 无法解析根元素前的注释（报 "Can't determine type for tag"，与真实问题无关，具误导性）
