# 0.0.2

发布日期：2026-10-03

日历视图与提醒管理能力扩展版本。

## 功能迭代

### 1. 日历视图（月/周/三天/单天）

按 003 spec 新增日历页：月视图、周视图、三天视图与单日时间轴视图，基于本地日历日计算周期间隔（修复跨时区日期偏移），时间轴标记采用固定布局避免错位。列表与日历入口样式统一。

### 2. 提醒管理能力扩展

- 分类复制：闹钟支持按分类批量复制，一次性闹钟过期后进入过期状态展示
- 冲突检测：创建/编辑时检测时间冲突（新增 `src/services/conflicts.ts` 及单测）
- 筛选排序：提醒列表支持按分类筛选与排序

### 3. 通知与稳定性修复

- 设置页展示通知权限状态，可直接跳转系统设置
- 修正提醒声音配置
- 修复数据库连接热更新后失效：连接获取前 `SELECT 1` 探活，失效时重置单例重开，解决 dev 环境热更新后 `shared object already released` 报错

## 工程与平台迭代

### 1. 版本号升级至 0.0.2

package.json / app.json 同步升级，确认日历与管理能力为第二个版本主体。
