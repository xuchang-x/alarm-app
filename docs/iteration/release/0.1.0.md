# 0.1.0

发布日期：2026-10-05

## 功能迭代

### 1. 深色模式「经典紫夜」+ 设置页主题切换（008 核心）

- SKIN 语义皮肤层扩展为双 palette 工厂（SKIN_LIGHT / SKIN_DARK），深色为「经典紫夜」配色，语义键补齐 card / cardPressed / cardDisabledBg / cardDisabledBorder / successSoft / dangerSoft / sheetBackdrop
- 设置页新增「外观 · 主题」三选项（跟随系统 / 浅色 / 深色），切换后写入 DB 并同步原生 SharedPreferences 落盘
- 冷启动首帧无闪：JS bundle 求值阶段经 AlarmRing.getSkinTheme 同步读原生偏好定型皮肤（原生侧新增该同步函数），模块级 StyleSheet 冻结前已取到正确色值
- 全部组件硬编码色清零：theme.ts 之外不再有任何十六进制色值，Switch 圆点、保存/确认按钮文字、弹层遮罩等统一走 SKIN 语义键

### 2. 每天每周闹钟左滑跳过一次（与周期调度策略统一）

- 列表页每天/每周闹钟支持左滑「跳过一次」，当日不出现在响铃计划中，与周期闹钟的 skip 能力统一
- 今日页已响过的周期行禁用左滑，避免跳过错位到下一轮

### 3. 铃声体验修复

- 修复从音乐库选择铃声报错「暂时无法访问音乐库」（权限回退与持久化 URI 兼容）
- 修复静音/震动模式下试听无声（试听走媒体音量通道）
- 修复通知不可见导致闹钟响后无法关闭

## 代码梳理（核心功能不变）

一轮逐文件清理，净删约 240 行：

- 删死代码：CycleSettings 组件（零引用）、alarm-repository 的 toggleAlarm / clearAdjustments、utils/date 的 isDateEqual、settings-repository 重复建表 DDL

## 工程与平台迭代

### 1. 发布包瘦身：release APK 101MB → 21MB

- arm64 单架构 + R8 混淆 + 资源收缩 + so zip 压缩（配置在本地 android/gradle.properties，不入库）；体积构成分析：原生库四架构 75MB → 单架构、dex 48MB → 17MB
- 修复 AlarmRingModule 误用不存在的 SyncFunction 标识符导致 release 编译失败（Expo SDK 56 模块级同步函数 DSL 是 Function）
- 修复 release 包切换主题无反馈：DevSettings 在 release 同样存在但 reload() 是 no-op，环境判断改用 __DEV__，release 下皮肤弹窗提供「立即重启」（原生 restartApp 杀进程拉起）

- jest 映射 stub .ogg 音频资产，解除测试环境加载二进制报错；全量 9 套件 102 用例通过
- APK 体积排查结论与 prebuild 版本号漂移经验沉淀进 dev-knowledge
