# 0.1.4

发布日期：2026-10-06

## 功能迭代

### 1. 响铃调度升级为全局单槽 setAlarmClock（业界标准，同 AOSP DeskClock）

- 调度策略从「每个闹钟各挂一个 setExactAndAllowWhileIdle 精确闹钟」改为「全局只挂一个最近的未来触发」：系统对每个 App 只保留最近一次 alarm clock，触发后全局重选，PendingIntent 数量收敛为 1
- 优势：Doze 下系统主动提前退出低电耗模式；状态栏/锁屏展示系统闹钟图标与下次响铃时间（用户可感知「已设上」）；国产 ROM 电池策略对 alarm clock 类闹钟存活率最高
- AlarmReceiver 不再携带 alarmId，到点由「已过期触发时间」推断响哪个闹钟（duePlan），响铃后清掉所有过期触发（含同分钟撞车）再全局重挂；新增 15 分钟迟到容忍窗口，超时不再补响
- rescheduleAll 兼容清理 0.1.4 之前逐闹钟挂载的旧 PendingIntent

### 2. 响铃可靠性三连修

- 响铃期间持唤醒锁，修复杀 App 息屏后铃声不响（600daf0）
- 修复响铃浮层点「关闭/稍后提醒」后反复弹出（df6f38a）
- 设置页新增「后台运行保障」入口：引导用户开启自启动与电池白名单，降低国产 ROM 划卡片/一键清理等同强停导致的闹钟被清概率（244ac67）
