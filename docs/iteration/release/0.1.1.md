# 0.1.1

发布日期：2026-10-05

## 功能迭代

### 1. 主题切换响应式改造：去掉重启，全组件实时变色

- 主题切换不再依赖 JS 重载 / 原生重启：新增 zustand 皮肤 store（主题版本号驱动）+ `useSkinStyles` hook，`applySkinTheme` 原地覆写 SKIN/COLORS（引用不变），组件样式表由模块级 `StyleSheet.create` 冻结色值改为 `createStyles()` 工厂 + hook 订阅，版本号变化时自动重建样式并重渲染
- 全量覆盖 28 处组件：4 个 Tab 页、创建/编辑页、SkinAlert、PageHeader、EmptyState、Fab、SkinDatePicker（原生日期弹窗主题跟随）、alarm-form 8 个表单组件、闹钟卡片/筛选/计划/今日时间轴等列表组件；切主题零重启、零跳屏，即时生效
- 「跟随系统」实时响应：注册 Appearance 监听，系统深浅切换时无需重启 App 即时跟随
- 设置页主题切换文案更新为「即时生效，无需重启」；移除 release 包的「立即重启」兜底路径，原生侧 restartApp 同步清理（getSkinTheme/setSkinTheme 保留供冷启动定型）
- 冷启动首帧无闪能力保留：JS bundle 求值阶段仍经 AlarmRing.getSkinTheme 同步定型皮肤，模块级 StyleSheet 冻结前已取到正确色值
