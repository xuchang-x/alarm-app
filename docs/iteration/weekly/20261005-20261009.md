- 响铃全屏界面（0.1.3 核心）：调研业界实践（AOSP/Google 时钟的 full-screen intent + 专用响铃 Activity 模式）后，FSI 从 launcher 改指专用原生 AlarmRingActivity——App 被杀/后台/锁屏时闹钟触发直接全屏弹出响铃界面（盖锁屏亮屏 + 请求解锁，实测 ~107ms 显示），关闭/稍后提醒/30 秒自停经 ACTION_RING_STOPPED 广播联动自动退出，界面深浅色跟随 App 内皮肤选择；FSI 权限受限自动降级 heads-up 横幅，前台仍走 RingOverlay 浮层双通道互补
- 东八区日期时区缺陷修复（0.1.3）：SkinDatePicker Android 弹窗按 UTC 零点解读 selection 导致回显/回传偏早一天、一次性副本 toISOString 算明天偏早一天，统一收敛到本地日历日运算（dateToUtcMidnight + addDaysToDate）+ 3 个新单测
- 提醒响铃循环播放够 30 秒（0.1.2 核心新能力）：自研原生模块 alarm-ring，短铃循环补齐、长铃截断，时长常量可配；响铃计划原生持久化，App 被杀/设备重启不丢；响铃通知带关闭/贪睡按钮
- 通知调度可靠性：预调度按 60 条上限截断防 iOS 静默丢弃、落库/调度失败一致性提示、回前台自动补排、过期一次性闹钟自动归位
- 通知交互修正：点击通知跳编辑页不再静默关闭闹钟
- 交互防护：滑动删除二次确认、编辑页未保存确认、异步操作错误提示、过去日期禁止选择
- 007 提示音与自定义铃声（0.0.5 核心）：每个闹钟独立铃声——10 个内置提示音三档分组可选（默认 Classic Alarm）、逐项试听、本地音乐选歌铃声、铃声随响铃计划透传原生 + 三级回退保底
- 响铃链路缺陷修复（含 0.0.4 遗留关键 bug）：原生模块 New Architecture 下不可达导致响铃一直静默降级、当天一次性/周期闹钟不响、新装用户缺精确闹钟权限延迟 100 秒响、铃声 JSON null 误读为 "null" 字符串；修复后实测精确触发毫秒级偏差、30 秒自停
