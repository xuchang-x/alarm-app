# 008 深色模式 视觉方向调研

调研目的：为深色主题选定一套完整配色 token。5 套候选为**自制视觉方向**（用户从 AI 生成设计图中确认），方法论参考公开设计规范；不虚构第三方来源。

| # | 方案 | 方法论参考 | 许可证 | 适配范围 | 适合本项目的原因 |
|---:|---|---|---|---|---|
| 0 | 当前浅色（基线对照） | —（本项目 `src/constants/theme.ts` SKIN） | 项目自有 | React Native | 模式 C 基线：验证深色实现后浅色零回归 |
| 1 | 经典紫夜 Material | [Material Design 3 深色主题](https://m3.material.io/styles/color/system/overview)（规范页，仅方法论参考） | 规范文档（CC BY 4.0） | 跨端视觉参考 | 最稳的深色实践：近黑底 + 卡片逐级提亮 + 品牌色提亮降饱和 |
| 2 | 深空靛蓝 | 自制方向（带蓝紫氛围的深底） | — | React Native | 与品牌紫同色相，整体氛围更「夜」 |
| 3 | OLED 纯黑 | 自制方向（OLED 省电取向，社区常见实践） | — | React Native | 纯黑底 OLED 省电明显，品牌紫在纯黑上最鲜明 |
| 4 | 暖夜拿铁 | 自制方向（暖棕调夜色） | — | React Native | 暖调夜间更护眼，适合睡前查看 |
| 5 | 高对比薰衣草 | 自制方向（高对比深色） | — | React Native | 弱光环境下辨识度最高，主色极亮 |

## 套用到当前项目后的方向

1. **经典紫夜 Material**：`#121212` 底、`#1E1B2E` 卡、主色 `#6C5CE7→#8B7CF7` 提亮，selected 态用半透明主色底。
2. **深空靛蓝**：`#0F1226` 底、`#191D36` 卡，全页带靛蓝氛围，hero 卡更亮一档。
3. **OLED 纯黑**：`#000000` 底、`#111014` 卡，靠色阶分层，品牌紫保持原值最抢眼。
4. **暖夜拿铁**：`#1A1714` 暖底、`#262019` 暖卡，主色暖紫 `#A98BF0`，文字暖白。
5. **高对比薰衣草**：`#17141F` 底 + 极亮 `#A78BFA` 主色，深底上 everything 清晰。

## 推荐观察点

- hero「下一次响铃」卡在深色下的层次（是全页视觉焦点）
- 时间轴状态竖条 / 已响置灰的层级是否仍清晰
- 试听按钮、开关、chip 选中态在深色下的辨识度
- 迁移成本：5 套都只动 palette 层，实施成本相同；差异纯在观感

## 当前选定（已确认）

- 视觉基础：方案 1 经典紫夜 Material（用户 2026-10-05 确认）
- 实施方式：`SKIN` 增加深色 palette + `createSkin` 工厂，业务代码零改动；组件级 `StyleSheet` 在求值时定型，故主题在 bundle 求值时通过原生同步读取（alarm-ring `getSkinTheme`）一次性确定，切换后走 `DevSettings.reload()`（dev）或重启提示（release）生效，不做运行时热切换
- 「跟随系统」在启动时经 `Appearance.getColorScheme()` 快照定型，系统切换下次启动生效
