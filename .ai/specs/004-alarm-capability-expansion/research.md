# 004 闹钟能力扩展 UI 原型说明

本 Spec 沿用已经确认的 Eva / UI Kitten 视觉方向。原型用于验证 P0/P1 能力在当前页面中的信息层级和操作入口，不重新比较多套视觉方案。

| 方案 | 开源来源 | 许可证 | 适配范围 | 本次采用方式 |
|---|---|---|---|---|
| Eva / UI Kitten | [akveo/react-native-ui-kitten](https://github.com/akveo/react-native-ui-kitten) | MIT | React Native | 延续紫色主色、分类色点、白色卡片和轻量提示弹层 |

## 页面覆盖

- 列表管理：搜索、类型/分类筛选、排序、复制和过期状态。
- 分类设置：工作、生活、运动、其他预设分类。
- 冲突提示：创建或编辑时提示未来 30 天同一时间的提醒。
- 一次性完成态：计划日期过去后显示已过期，并保留编辑入口。

## 当前实现边界

- 冲突提示是非阻断确认，用户可以继续保存。
- 分类使用预设颜色，不开放自定义颜色。
- 导入导出、云同步、自定义铃声和位置触发暂不进入当前原型。
