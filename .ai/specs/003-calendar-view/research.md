# 003 日历视图 UI 原型说明

本 Spec 沿用已经确认的 Eva / UI Kitten 视觉方向，没有重新生成多套风格。原型只借鉴设计语言和组件组织方式，不直接复制第三方页面。

| 方案 | 开源来源 | 许可证 | 适配范围 | 本次采用方式 |
|---|---|---|---|---|
| Eva / UI Kitten | [akveo/react-native-ui-kitten](https://github.com/akveo/react-native-ui-kitten) | MIT | React Native | 延续浅色暖灰背景、紫色主色、白色圆角卡片和状态色标记 |

## 页面覆盖

- 月视图：42 格月份网格、提醒数量、分类色点、选中日期详情。
- 周视图：7 列日期和按小时排列的提醒块。
- 三天视图：3 列近期日期和按小时排列的提醒块。
- 单天视图：当天时间轴、空状态和编辑入口。

## 当前设计决策

- 三天视图每次前后移动一天。
- 周视图从周一开始。
- 月视图点击日期后在页面下方展开当天详情。
- 默认只展示已开启提醒，通过筛选开关查看暂停提醒。
